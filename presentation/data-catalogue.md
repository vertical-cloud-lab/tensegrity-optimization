# Data Catalogue — tensegrity-optimization

A comprehensive, manually-swept catalogue of where all existing project data lives: every issue comment, every PR comment (including inline review comments), and every file on every branch, as of **2026-07-26**. Compiled for IDETC presentation prep (issue #83 / PR #84).

Structure: **Part 1** is a quick-reference index organized by data type (start here when hunting an asset for a slide or figure). **Part 2** catalogues each issue/PR thread, asset by asset, with direct links and comment provenance. **Part 3** catalogues committed files per branch (branches that only duplicate `main` are listed at the end).

⚠️ marks files >5 MB. Comment-attachment URLs (`github.com/user-attachments/...`) require being logged in to GitHub; Box links are public.
