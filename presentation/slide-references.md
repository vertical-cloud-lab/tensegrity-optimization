videos, print timelapses, high-speed and phone slow-motion drop footage,
search-space animations, the parameter and seed-design renders, the
accelerometer data figures, and the workflow diagrams. Selected public links:

  <https://github.com/vertical-cloud-lab/tensegrity-optimization>

  [Icosahedron Tensegrity Kit by Tensegrity Adventures](https://www.tensegrityadventures.com/shop/p/icosahedron-tensegrity),
  a 6-bar tensegrity icosahedron, the same configuration as NASA's SUPERball
  bot.
- [Multi-material print timelapse of a T3 specimen](https://www.youtube.com/watch?v=nQNmi-NiL5I),
  BYU Vertical Cloud Lab.

  across about 50 specimens in about 3 months):
  [tensegrity-optimization issue #101](https://github.com/vertical-cloud-lab/tensegrity-optimization/issues/101).
