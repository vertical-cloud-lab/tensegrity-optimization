# Inputs and outputs of the LOGO-CV baseline comparison

Everything here is either a verbatim copy with the provenance below, or
generated by a script in the parent directory.

## Vendored (verbatim) from the audit branch

Branch `claude/cv-signal-audit-20260922` at commit `6964ac2`, directory
`analysis/cv-signal-audit/data/`:

- `sim-features.csv`: one row per design-mapped article (46), with the six
  `sim_*` columns the simulation-feature runs append to the fit space (Tier C
  and Tier B transmissibility analogues, Tier C peak tendon energy and
  stroke, Tier B ringdown frequency and damping), from the #33 simulators
  (branch `copilot/explore-simulations-for-tensegrity` at `94e53a8`) run at
  the design's print geometry with the design-mean weighed mass, so reprint
  twins share identical features. Written by that branch's
  `compute_sim_features.py`. The `batch` column is the print session.
- `ax-runs/<run>/`: the Ax SAASBO leave-one-design-out runs, every one at
  256 NUTS samples / 512 warmup steps per fold, 35 design folds over 44
  articles, reprint pairs held out together, `torch.manual_seed(fold_index)`
  per fold, campaign code at `bbf7a62`, the campaign's round-5 snapshot:

  | directory | fit space | written by (on the audit branch) |
  |---|---|---|
  | `full-nuts-rerun/` | the campaign's 12 parameters | `rerun_logocv_full_nuts.py` (the manuscript's `t3-prism-bo-round5-logocv.csv`) |
  | `ablation-six-param/` | 6: five shape coordinates + weighed printed mass | `rerun_logocv_param_ablation.py --variant six-param` |
  | `ablation-shape-only/` | 5: shape coordinates | `rerun_logocv_param_ablation.py --variant shape-only` |
  | `sim-features-shape-sim/` | 5 shape + 6 sim features | `rerun_logocv_sim_features.py --variant shape-sim` |
  | `sim-features-twelve-sim/` | 12 + 6 sim features | `rerun_logocv_sim_features.py --variant twelve-sim` |
  | `sim-features-sim-only/` | 6 sim features alone | `rerun_logocv_sim_features.py --variant sim-only` |

  Each directory holds the campaign-format `t3-prism-bo-round5-logocv.csv`
  (one row per article and objective: observed mean and SEM, held-out
  posterior mean and sd), Ax's `...-diagnostics.json`, and the run's
  `state.json` (settings, seed scheme, per-fold timings). `full-nuts-rerun/`
  also keeps `folds.jsonl`, the per-fold checkpoint with every article's
  full parameterization, which is where `article-features.csv` takes the
  twelve campaign parameters from.

## Produced on this branch

- `ax-six-sim/`: the new Ax run, six original parameters plus the six
  simulation features (12 parameters, none a print-process setting), by
  `../rerun_logocv_six_param_sim.py --variant six-sim` under the same
  protocol as the vendored runs (fold order asserted equal to
  `full-nuts-rerun`, same per-fold seeds, four queue workers at one torch
  thread each, one commit per fold). Same layout as the vendored runs plus
  `folds.jsonl`.
- `article-features.csv`: one row per LOGO article (44): print id, Ax arm,
  design fold key and fold index, print session, the twelve campaign
  parameters exactly as Ax fitted them, the six simulation features, and
  the observed mean and SEM of both objectives. Built by
  `../logocv_baselines.py --build-table`, which asserts the observed values
  equal `manuscript/data/t3-prism-bo-round5-logocv.csv`.
- `baselines/<model>-<space>.csv`: scikit-learn baselines fitted under the
  identical leave-one-design-out protocol, in the campaign CSV layout, with a
  `<model>-<space>-fits.json` recording the hyperparameters each fold chose
  (`../logocv_baselines.py --fit`). Models and spaces are defined in that
  script's docstring.
