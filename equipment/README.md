# Equipment

Documentation for the lab equipment we plan to use to characterize the
tensegrity-inspired impact absorbers (refs [#17][i17], [#23][i23]).

| Equipment | Purpose | Folder |
| --- | --- | --- |
| Lansmont Model 23 (M23) Shock Test System | Programmable drop / shock pulses on printed specimens; cushion-curve testing | [`lansmont-m23/`](lansmont-m23/) |
| Polytec QTec single-point Laser Doppler Vibrometer (≈100 kHz) | Non-contact transient surface-velocity measurement during/after impact; modal characterization | [`polytec-qtec/`](polytec-qtec/) |

Source for this list: drop tower issue [#27][i27] (Jeff confirmed the M23 and the
Polytec QTec; high-speed cameras are also available — to be documented separately
once the specific model is confirmed).

A literature survey of peer-reviewed publications that use either instrument for
architected materials, lattices, foams, packaging cushions, tensegrity, prosthetics,
crutch tips, and 3D-printed energy absorbers has been completed via Edison
(LITERATURE_HIGH, task `1a0f4a70-3297-44d1-860a-dfcdd551e561`). The full verbatim
answer (with citations) is in
[`../edison-trajectories/2026-05-08-equipment-m23-qtec-1a0f4a70.md`](../edison-trajectories/2026-05-08-equipment-m23-qtec-1a0f4a70.md);
per-instrument highlights are in
[`lansmont-m23/literature.md`](lansmont-m23/literature.md) and
[`polytec-qtec/literature.md`](polytec-qtec/literature.md).
