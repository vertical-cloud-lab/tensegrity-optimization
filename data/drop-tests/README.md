# Drop-test data

Raw instrumentation data and analysis outputs for the first crush/drop tests
(issue #36).

- `raw/` — TP4 Time-Domain export files (`Signal 10–14`), 4-channel
  accelerometer, 125 kHz, 0.2 s window. Posted by @me-madsen,
  [issue #36](https://github.com/vertical-cloud-lab/tensegrity-optimization/issues/36#issuecomment-4568785386)
  (tests run Friday May 22).
- `figures/` — plots generated by
  [`scripts/analysis/drop_test_analysis.py`](../../scripts/analysis/drop_test_analysis.py).

Analysis and interpretation: [`docs/drop-test-analysis.md`](../../docs/drop-test-analysis.md).

Regenerate the figures with:

```bash
pip install numpy scipy matplotlib
python scripts/analysis/drop_test_analysis.py
```
