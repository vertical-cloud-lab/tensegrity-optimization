# Key-seat **+ wax retainer** input-output drop tests (specimen `prc1kn`)

Raw TP4 accelerometer exports for the **wax-retainer follow-up** run by @ctrhjk,
posted on
[PR #67](https://github.com/vertical-cloud-lab/tensegrity-optimization/pull/67#issuecomment-4838901017).

This is a direct follow-up to the bare
[key-seat run](../key-mounted/README.md). The instrumentation is the same
input-output pair — a single-axis accelerometer wax-mounted on the bottom
acrylic plate is the **input** (CH5, triggered), a tri-axis accelerometer in the
top-vertex **key-seat** is the **output** (CH2/CH3/CH4), and the bungees are
removed. The **one** change under test here is the **output-sensor retention**:
in the bare key-seat run the tri-axis sat by press-fit alone and eventually
**fell off** mid-run, so @ctrhjk has now added **wax inside the housing** to
retain it. The goal is to confirm the output stays drift-free with the wax
retainer in (rather than the wax reintroducing the mount creep the original
hot-glue mount showed).

The specimen `prc1kn` is the same **deliberately-failed print** (bubbles in its
TPU cable); it is used only to exercise the mount + DAQ, **not** to compare
geometry.

## Recording setup

One specimen, **five drops** (`Signal{7,8,9,10,11}` = drops 1…5), drop height
**13 in**. Channels and DAQ are identical to the key-seat / input-output series.

| Channel | Sensor | Mount | Role | Full scale (G) | Sensitivity (mV/G) | Trigger |
|---|---|---|---|--:|--:|---|
| CH2 | tri-axis | vertex **key-seat + wax** | output | 14492.8 | 0.69  | No |
| CH3 | tri-axis | vertex **key-seat + wax** | output | 14992.5 | 0.667 | No |
| CH4 | tri-axis | vertex **key-seat + wax** | output | 13624.0 | 0.734 | No |
| CH5 | single-axis | base plate (wax) | **input** | 9442.9 | 1.059 | **Yes** (1000 G) |

All channels AC-coupled, ICP on, Half-Sine waveform analysis. DAQ: record time
200 ms, 125 kHz (8 µs), 25000 samples, 2 % (4 ms) pre-trigger. The trigger is on
CH5 (the single-axis input on the base plate).

## Files

Each CSV is a TP4 Time-Domain export: a short header block, then columns
`Time (sec), CH2 Acc (G's), CH3 Acc (G's), CH4 Acc (G's), CH5 Acc (G's)`.

| File | Drop # |
|---|---|
| `raw/key_mounted_wax_Signal7.csv`  | 1 |
| `raw/key_mounted_wax_Signal8.csv`  | 2 |
| `raw/key_mounted_wax_Signal9.csv`  | 3 |
| `raw/key_mounted_wax_Signal10.csv` | 4 |
| `raw/key_mounted_wax_Signal11.csv` | 5 |

**File-name note:** the original exports were named `Key mounted2_Signal{7..11}`
(the `Signal{n}` index is the TP4 *capture* number — this run continues the
capture counter from the bare key-seat run, hence 7…11). They are renamed here to
`key_mounted_wax_Signal{n}.csv` and map contiguously to drops 1…5.

## Notes from @ctrhjk

1. Wax was added **inside the key-seat housing** to retain the tri-axis output
   sensor, fixing the press-fit-only fall-off seen in the bare key-seat run.
2. The single-axis input sensor is wax-mounted on the base plate; bungees
   removed; all other settings identical to the previous run.
3. The specimen is the failed print `prc1kn` (TPU bubbles), used to validate the
   mount/DAQ — not a geometry comparison.
