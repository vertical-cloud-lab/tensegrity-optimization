# Input-output accelerometer drop tests (T3 prisms)

Raw TP4 accelerometer exports for the **input-output (transmissibility)**
instrumentation design proposed and run by @ctrhjk, posted on
[PR #67](https://github.com/vertical-cloud-lab/tensegrity-optimization/pull/67#issuecomment-4804858562).

The idea: pair a single-axis accelerometer on the **bottom acrylic plate** (the
**input** — it sees the plate strike) with a tri-axis accelerometer hot-glued to
the **top vertex** (the **output** — it sees what the specimen transmits). The
ratio output/input is the candidate transmissibility objective.

**The bungees were removed for this series (pretension off)**, so the
bungee-driven specimen lift-off that contaminated earlier drops is no longer in
play and the strike is delivered by the falling drop-load directly.

## Recording setup

Four distinct-geometry specimens, **five drops each** (`Signal1`…`Signal5` is
drop 1…5, *not* a channel index), drop height **13 in**.

| Channel | Sensor | Mount | Role | Full scale (G) | Sensitivity (mV/G) | Trigger |
|---|---|---|---|--:|--:|---|
| CH2 | tri-axis | top vertex | output | 14492.8 | 0.69  | No |
| CH3 | tri-axis | top vertex | output | 14992.5 | 0.667 | No |
| CH4 | tri-axis | top vertex | output | 13624.0 | 0.734 | No |
| CH5 | single-axis | base plate | **input** | 9442.9 | 1.059 | **Yes** (1000 G) |

All channels AC-coupled, ICP on, Half-Sine waveform analysis. DAQ: record time
200 ms, 125 kHz (8 µs), 25000 samples, 2 % (4 ms) pre-trigger. **The trigger was
moved to CH5** (the single-axis input on the base plate) for this series.

## Files

Each CSV is a TP4 Time-Domain export: a short header block, then columns
`Time (sec), CH2 Acc (G's), CH3 Acc (G's), CH4 Acc (G's), CH5 Acc (G's)`.

## Notes from @ctrhjk

1. The single-axis accelerometer on the base plate is the **input** sensor and
   the tri-axis on the vertex top is the **output** sensor.
2. The tri-axis was secured to the rounded vertex with a hot-glue gun, the same
   way as the earlier vertex tests.
3. **No bungees attached to the drop-load** for this run — the bungee pretension
   was removed.
4. Each of the four specimens was dropped five times at 13 in.
