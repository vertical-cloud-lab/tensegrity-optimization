# Standards and implementation audit

## Immediate finding

**The repository filter is not the SAE J211 Appendix C filter.** Its two-pass bandwidth is about 20% too small. The published “12× attenuation at 550 Hz” is a property of the repository implementation, not of a correct CFC-180 filter. A correct Appendix C CFC-180 filter attenuates a 550 Hz sinusoidal amplitude by **5.68×**, not 12.3×.

There are two corrections to the proposed interpretation:

1. Appendix C’s factor **2.0775 sets the −3 dB frequency of each 2-pole pass**. Forward and backward application produces a 4-pole phaseless response.
2. The resulting pair is −3 dB at **1.6667 × CFC**, not exactly 1.65 × CFC. Thus CFC-180 is 300 Hz and CFC-60 is 100 Hz. The 1.65 ratio is the tabulated characteristic frequency for CFC-1000 in the response corridor, not the exact Appendix C ratio for every class.

These clause-level findings were checked against the publicly accessible text of **SAE J211-1:1995**, especially §§4.2, 9.1–9.4 and Appendix C, and **ISO 6487:2015**, especially §4.1, Tables 1–2 and informative Annex A. The current SAE edition is J211/1_202208, but its complete clause text was not publicly accessible, so I do not present quotations from that edition as verified. The 2014 SAE preview says its CFC-60/180 corridors were derived around the March 1995 Appendix C filters.

## II. Correct filter definition

### Appendix C recurrence

SAE J211-1:1995 Appendix C, Eq. C1 defines one 2-pole pass as

$$
y_i=a_0x_i+a_1x_{i-1}+a_2x_{i-2}+b_1y_{i-1}+b_2y_{i-2},
$$

with

$$
\omega_d=2\pi(2.0775)(\mathrm{CFC}), \qquad
\omega_a=\tan\left(\frac{\omega_dT}{2}\right),
$$

and the coefficients given in the question. Appendix C then says that the data are passed through the 2-pole filter twice, forward and backward, to make a 4-pole phaseless filter.

For an analog second-order Butterworth pass,

$$
|H_1(f)|=\frac{1}{\sqrt{1+(f/f_p)^4}}.
$$

Forward-backward filtering gives

$$
|H_{FB}(f)|=|H_1(f)|^2=\frac{1}{1+(f/f_p)^4}.
$$

The pair reaches $1/\sqrt{2}$ at

$$
\frac{f_{-3\mathrm{dB},FB}}{f_p}=(\sqrt{2}-1)^{1/4}=0.8022433.
$$

Therefore

$$
f_{-3\mathrm{dB},FB}=0.8022433(2.0775)(\mathrm{CFC})
=1.6666604(\mathrm{CFC}).
$$

This is 100.0 Hz for CFC-60 and 300.0 Hz for CFC-180, matching ISO 6487:2015 Table 2’s $F_N$ values. The standard’s tables define response corridors, so describing every class solely by one exact “corner” is an approximation, especially CFC-600 and CFC-1000.

### Drop-in implementation

```python
import numpy as np
from scipy import signal


def cfc_coefficients(fs, cfc):
    """SAE J211-1:1995 Appendix C 2-pole coefficients."""
    fs = float(fs)
    cfc = float(cfc)
    if fs <= 2.0 * 2.0775 * cfc:
        raise ValueError("Sampling rate is too low for this digital design.")

    wa = np.tan(np.pi * 2.0775 * cfc / fs)
    den = 1.0 + np.sqrt(2.0) * wa + wa**2

    a0 = wa**2 / den
    b1 = -2.0 * (wa**2 - 1.0) / den
    b2 = (-1.0 + np.sqrt(2.0) * wa - wa**2) / den

    # J211 puts +b1*y[n-1] + b2*y[n-2] on the RHS.
    # scipy.signal uses denominator [1, -b1, -b2].
    b = np.array([a0, 2.0 * a0, a0])
    a = np.array([1.0, -b1, -b2])
    return b, a


def cfc_filter(x, fs, cfc, pad_ms=10.0):
    """Appendix-C core with endpoint reflection made explicit.

    Requires a record longer than the requested padding. Filtering does not
    repair inadequate real pre-event or post-event acquisition.
    """
    x = np.asarray(x, dtype=float)
    b, a = cfc_coefficients(fs, cfc)

    padlen = int(np.ceil(float(fs) * pad_ms / 1000.0))
    if x.size <= padlen:
        raise ValueError("Record is too short for the requested endpoint padding.")

    return signal.filtfilt(
        b, a, x,
        padtype="odd",   # reflection about the endpoint value
        padlen=padlen,
    )
```

The coefficient arrays are numerically identical, to floating-point precision, to:

```python
signal.butter(2, 2.0775 * cfc, btype="low", fs=fs)
```

The explicit recurrence is preferable in audited code because it exposes the standard’s factor and sign convention.

**Important qualification:** for CFC-600 and CFC-1000, SAE J211-1:1995 §9.4.1 permits any digital filter that meets the §4 response corridor; it specifically directs use of Appendix C for CFC-60 and CFC-180. Applying the Appendix C shape to all four classes is a consistent engineering choice, but corridor compliance should be checked numerically rather than asserted from the function name.

## IV. Standards clauses and implementation consequences

### A. Filter response and order of operations

* **SAE J211-1:1995 §4.2:** CFC-60 and CFC-180 are determined by the Appendix C algorithm; CFC-600 and CFC-1000 use response limits.
* **Appendix C, Eq. C1:** supplies the 2.0775 recurrence and directs forward/backward passage to make the 4-pole phaseless result.
* **§9.4.1:** filtering should precede nonlinear operations, explicitly including resultant-vector calculations. It also says the digital filter type should be reported.
* **ISO 6487:2015 §4.1, Table 2:** gives CFC-60/180 corridor points, including $F_N=100$ and 300 Hz. Annex A is an informative example of the phaseless Butterworth algorithm.

Sources: [public SAE J211-1:1995 text](https://law.resource.org/pub/us/cfr/ibr/005/sae.j211-1.1995.html), [ISO 6487:2015 preview](https://cdn.standards.iteh.ai/samples/64041/60e1481a15544f4ea6b371073edd7ae6/ISO-6487-2015.pdf), and [current SAE J211/1_202208 landing page](https://saemobilus.sae.org/standards/j2111_202208-instrumentation-impact-test-part-1-electronic-instrumentation).

### B. Sample rate and anti-aliasing

**SAE J211-1:1995 §9.1** says presample filtering should prevent high-frequency components from producing aliasing and requires alias-induced error at $F_H$ not to exceed **0.1% of the channel amplitude class**. It also warns that post-filtering can hide overload.

**§9.2** recommends at least **10 × $F_H$** for installations using simple reconstruction. Both 125 kHz and 1.25 MHz exceed this by large margins for the stated classes. High digital sample rate alone does not establish compliance: the acquisition path still needs a documented analog anti-alias response, adequate headroom and no sensor/conditioner overload.

### C. Endpoint treatment

Appendix C says:

* Sufficient real pre-event and post-event data may be used so startup transients decay before the event.
* If pre-event data are unavailable, copy **at least 10 ms** at each end and transpose the copy about either zero or the endpoint, then discard the padding after filtering.
* Other startup algorithms are allowed if the user assesses their distortion; if pre-event data are unavailable, the method must be reported.

SciPy’s default for this filter is only nine samples. At 1.25 MHz that is **7.2 µs**. A numerical impulse-response check of the correct single-pass CFC-180 section found its response remained above 1% of peak until approximately **3.28 ms** and above 0.1% until approximately **4.83 ms**. These are computational diagnostics, not quoted standard limits.

Therefore, nine-sample odd reflection is **not demonstrated adequate** for an impact beginning ~0.35 ms after record start. Odd reflection itself resembles Appendix C’s reflection about an endpoint; its default length is the problem. Ten-millisecond explicit padding follows the published example, but it cannot create genuine quiet pre-event data. Recollection remains the proper correction.

### D. Baseline correction

**SAE J211-1:1995 §9.4.2** says software should determine zero levels and calibration factors rather than assume no drift. It also specifically warns that zero-offset errors in orthogonal components cause errors in resultants that can be difficult to detect.

I found **no universal pre-event window or minimum baseline duration in the verified SAE J211 or ISO 6487 clauses**. Consequently:

* “The standard requires a 10 ms baseline mean” would be false. Appendix C’s 10 ms is endpoint-padding guidance, not a zero-estimation rule.
* A full-record median is not expressly prohibited by a clause, but it is not endorsed and is not a defensible zero estimator when the record contains the impact and post-impact response.
* A baseline rule must be justified by quiet pre-event stationarity, instrument drift and the required uncertainty, then documented.

Your proposed 2 ms pre-trigger contains only 1.1 cycles at 550 Hz. For this setup I recommend **≥10 ms of verified quiet pre-trigger, preferably 20 ms**, plus 50–100 ms after impact or longer until the filtered response and integrated velocity have demonstrably stabilized. This is an engineering recommendation based on the filter transient, several structural cycles and baseline precision, not a quoted J211 minimum.

The current 0.35 ms records provide only ~438 samples despite the high sampling rate. More samples do not solve deterministic ring-in, trigger leakage, mounting motion or offset drift. The reported baseline-window sequence, 1.365/1.317/1.228/1.194 versus 0.989, spans changes of tens of percent while the target effect is 1–3%. **No estimator selected from these same records can be certified to 1% from the available evidence. Recollect.**

### E. Vector magnitude

The proper sequence is:

1. Estimate and remove bias separately on CH2, CH3 and CH4.
2. Apply the same filter class and endpoint policy to each axis.
3. Form $r(t)=\sqrt{x(t)^2+y(t)^2+z(t)^2}$.
4. Extract the resultant peak.

For a residual offset vector $e$ and true acceleration vector $a$, the first-order error away from zero is

$$
\|a+e\|-\|a\|\approx \frac{a\cdot e}{\|a\|},
$$

bounded in magnitude by $\|e\|$. Near zero, however, the norm has a positive floor, and taking the maximum adds selection bias. Three noisy axes also provide more contributions than one axis. Thus the resultant is not inherently unsound, but baseline uncertainty must be propagated or assessed by sensitivity analysis on each axis.

## V. Practical effect on reported quantities

Applying the same wrong linear filter to both channels cancels only under restrictive conditions: numerator and denominator must have proportionally identical spectral shapes, temporal waveforms and filter-induced peak changes. Those conditions are not met when peaks occur at different times and contain different modal content.

| Quantity | Consequence of corner error |
|---|---|
| **Peak G** | **Recompute.** Peak response depends on spectral composition and pulse shape. |
| **Pulse half-maximum width** | **Recompute.** Narrower filtering broadens pulses; the half-maximum threshold also moves when the peak moves. |
| **Delta-v by integration** | **Recompute from corrected baselines.** An ideal unity-DC low-pass does not change the integral of an infinite complete record, but finite windows, endpoint transients and DC bias do. Baseline error is especially damaging because velocity error grows as offset × integration time. |
| **T peak ratio** | **Recompute.** Partial cancellation is empirical, not guaranteed. The reported <1% CFC-180 change can be stated only as a sensitivity result for those 40 files. A +9% CFC-1000 change is material relative to 1–3% effects. |
| **Band-energy fractions** | **Recompute.** These are directly determined by the squared frequency response; the narrower filter changes both retained energy and band allocations. |
| **Trigger-crossing times from raw CH5** | Usually unaffected if computed before filtering and baseline choice does not alter the trigger definition. Verify the actual script order. |

The baseline problem supersedes the favorable <1% CFC-180 sensitivity result. A ratio that is stable to the filter correction but changes by tens of percent with plausible baseline windows is not established to 1%.

## VI. Is the peak ratio transmissibility?

### What the named standards cover

* [ASTM D3332](https://store.astm.org/d3332-99r23.html) addresses mechanical-shock fragility of products using shock machines.
* [ASTM D7136/D7136M](https://store.astm.org/d7136_d7136m-25.html) addresses drop-weight damage resistance of fiber-reinforced polymer composites.
* MIL-STD-810 Method 516 addresses shock test tailoring and evaluation.
* [ISO 18431-2](https://www.iso.org/standard/34591.html) addresses Fourier-transform processing; ISO 18431-4 addresses shock-response-spectrum analysis.
* [IEST-RP-DTE011](https://www.iest.org/Standards-RPs/Recommended-Practices/IEST-RP-DTE011) addresses shock/vibration transducer selection and application.

I found no definition in these sources equating transmissibility with the ratio of two nonconcurrent filtered time-domain peaks, especially where one peak is a tri-axial norm. It should be labeled descriptively, for example:

> **CFC-filtered output/input peak-acceleration ratio**

Calling it “transmissibility” risks implying a frequency-response function.

### Conditions needed for a transmissibility interpretation

A peak ratio approaches a meaningful system property only if:

* the system is approximately linear and time-invariant over the tested amplitude range;
* input and output directions and coordinate frames are physically matched;
* sensor and mounting bandwidths exceed the analysis band;
* input pulses have nearly identical shape and spectrum, not merely similar input peaks;
* boundary conditions, contact, absorber state and specimen preload are repeatable;
* peaks arise from the same response mechanism and preferably the same time neighborhood;
* baseline, saturation, clipping and endpoint effects are negligible;
* the ratio is stable across repeated input amplitudes.

A soft polyurethane stack plus a light compliant printed tensegrity specimen plausibly violates several conditions through nonlinear compression, changing contact area, amplitude-dependent stiffness/damping, different modal content and moving peak times. The ratio may still rank a fixed test configuration, but it should not be presented as a general transfer property.

### Better replacements

1. **Input-conditioned output shock response spectrum (SRS):** group or model output SRS conditional on measured input severity and pulse characteristics. ISO 18431-4 is the relevant SRS processing reference.
2. **Band-limited frequency-response estimate:** for matched scalar directions and approximately linear repeats,
   $$
   H_1(f)=\frac{G_{yx}(f)}{G_{xx}(f)}, \qquad
   \gamma^2(f)=\frac{|G_{xy}(f)|^2}{G_{xx}(f)G_{yy}(f)}.
   $$
3. Treat the three output axes separately for frequency-response estimation. A resultant magnitude is nonlinear and does not have an ordinary linear $H_1$ relationship to CH5.

For a single nonstationary transient, splitting one 20 ms record into Welch segments does not create defensible repeated realizations: different segments represent different phases of the event and violate the local stationarity assumption. Use time-aligned repeat drops as the ensemble, with consistent windows and enough post-event decay. Report the number of independent drops and uncertainty across drops.

There is **no universal standards-based minimum ensemble size** in the cited documents. Two records make the estimator algebraically possible but scientifically weak. As an engineering design rule, use at least **8–10 valid repeats per configuration for exploratory spectra and preferably 20 or more** when coherence and percent-level between-configuration effects will support decisions. That recommendation is inferential, not quoted. The required number should be set from repeat variability and confidence-interval width; with only a few repeats, report the transfer estimate without treating coherence as a precise validation statistic.

## VII. Accelerometer mounting

The reference correction is confirmed:

* **ISO 5348:2021**, “Mechanical vibration and shock — Mechanical mounting of accelerometers,” is the applicable mounting standard. Relevant provisions include §6.2.1 on operating frequency range, §6.3 on determining mounted fundamental resonance and §6.4.3 on adhesive mounting.
* **ISO 5347** was a series on calibration of vibration and shock pickups, not the general mounting standard. The series is withdrawn and was succeeded substantially by ISO 16063. See the [ISO 5347-1 record](https://www.iso.org/standard/11347.html) and [ISO 5348:2021 record](https://www.iso.org/standard/78160.html).

ISO 5348:2021 §6.2.1 says an accelerometer should operate well below its mounted fundamental resonance. For an undamped accelerometer mounted according to manufacturer recommendations, it gives approximate amplitude-error guides:

* up to ~20% of mounted resonance: usually <5% deviation;
* up to ~30%: usually <10%;
* up to ~50%: usually <3 dB.

It also notes that, for a single shock, a few-percent deviation can be expected when mounted resonance is ten times the inverse pulse duration.

There is no defensible universal statement such as “wax mounting is trustworthy to X kHz.” For a small printed polymer part, the limiting resonance may be the **accelerometer–wax–local-structure assembly**, not the accelerometer’s catalog resonance. Added sensor mass can also alter the specimen. Establish the upper trustworthy frequency by measuring the mounted resonance on a representative printed part, checking cross-axis response and cable strain, and demonstrating that sensor plus wax mass does not materially change the local mode. For <5% mounting-response error, use the conservative ISO guide of keeping analysis below approximately **0.2 times the measured mounted resonance**.
