# Campaign data snapshots used by the manuscript

All `t3-prism-bo-*` files are verbatim copies of the committed campaign
record, taken 2026-09-15 from branch `claude/issue-98-20260821-0103` at
commit `e25ebf5` (directory `bo/`). File-name convention on that branch:
`batch` = the Sobol seed batch (physical batch 1); `round1` = the first
model-recommended batch (`r2d2c*`, physical batch 2); `round3` = the
`drran*` batch (physical batch 3, Ax trials 28 to 36); `round4` = the
`corny*` batch (physical batch 4, Ax trials 37 to 45). The manuscript
numbers physical batches 1 to 4.

`round2-as-printed-solid-mass-projection.csv` and
`round3-candidate-constant-printed-mass.csv` are the two archived
recommendation sets discussed in the SI printed-mass section (provenance
fixed during the 2026-08-22 referee pass).

The dummy dataset `round2-measured-DUMMY.csv` and its generator were
removed on 2026-09-15: the real batch-2, 3, and 4 measurements above
supersede them.

Four further files were snapshotted later on 2026-09-15 from the same
branch at commit `bbf7a62`, the state after the lab confirmed the
`2dranN` articles as re-prints of `drranN` (same Ax trial) and the nine
reprint sessions were ingested as distinct completed trials:
`t3-prism-bo-round3-repeatability.csv` (the nine confirmed print pairs
behind the manuscript's repeatability table),
`t3-prism-bo-round3-reprint-drop-results.csv` (the stabilized 2dran
sessions), and `t3-prism-bo-round5-logocv.csv` plus
`t3-prism-bo-round5-logocv-diagnostics.json` (leave-one-design-out CV
over all 44 articles, reprint pairs held out together). The
`t3-prism-bo-front-evolution.csv` values were re-verified unchanged at
that commit; the corresponding LOGO figure snapshot is
`figures/bo/t3-prism-bo-round5-logocv.png`.

## Print-covariate audit files (added 2026-09-22)

- `t3-prism-bo-batch-print-key.csv`: the seed-batch (Sobol) print key,
  snapshotted 2026-09-22 from branch `claude/issue-98-20260821-0103` at
  commit `3ad4dd6` (directory `bo/`, same convention as the other keys).
  Carries the per-article chamber RH and visual-defect notes from the
  issue #98 print log.
- `byu-eb-weather-hourly.csv`: hourly outdoor temperature and relative
  humidity for the BYU engineering-building area (40.2465 N, 111.6478 W,
  model elevation 1425 m), 2026-07-25 to 2026-09-15 local time, pulled
  2026-09-22 from the Open-Meteo historical archive
  (archive-api.open-meteo.com, ERA5-based reanalysis). These are
  reanalysis-grid values, not an on-site sensor.
- `t3-prism-article-print-covariates.csv`: per-article covariate table for
  the 44 LOGO-CV articles (print session and window, chamber RH, defect
  flags, outdoor weather over the print window, documented TPU spool age,
  nozzle, LOGO residuals), generated by
  `scripts/figures/print_covariate_audit.py`. Print-session windows and
  TPU events are reconstructed from the GitHub record; see the script
  docstring for sources and caveats (seed windows are approximate, and no
  TPU spool swap is documented after 2026-07-13, so spool age assumes the
  same spool stayed loaded).
